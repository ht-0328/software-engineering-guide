# 書籍の抽出テキストの探し方

## 使う場面

`research/extracted/` の本文から根拠を探すとき。

**1冊で40万字ある。先頭から読むと、それだけで文脈窓を使い切る。** 実測では、1冊を通して読ませた調査が約98,000トークンを消費した。探してから読む。

## 何が置いてあるか

出典IDごとに、変換器の違う2つの本文と、1つの情報ファイルがある。

| ファイル | 中身 |
|---|---|
| `<出典ID>.poppler.txt` | 本文。段組の復元がよい。**まずこちらを使う** |
| `<出典ID>.pypdf.txt` | 本文。poppler で崩れたときの控え |
| `<出典ID>.info.txt` | 書名、著者、ページ数、PDFのハッシュ |

**ページの区切り方が2つで違う。**

| 変換器 | 区切り |
|---|---|
| poppler | 改ページ文字（`\f`）をページの末尾に置く |
| pypdf | `===== PAGE 12 =====` という行を挟む |

抽出ずみの出典IDは `ls research/extracted/` で分かる。**無いものは未抽出である。** 抽出は依頼した側が行う。取り出そうとしない。

## 手順

写して、終わったものに印を付ける。

```text
- [ ] 手順1: 探す語を決める
- [ ] 手順2: 該当行とページ番号を出す
- [ ] 手順3: 前後を読む
- [ ] 手順4: 出典の書き方を確かめる
```

### 手順1 探す語を決める

**書籍は書き手の語彙で書かれている。こちらが考えた語では当たらないことがある。**

まず広い語1つで引き、返ってきた本文から本が使っている語を拾う。そのうえで語を足して絞る。

### 手順2 該当行とページ番号を出す

`grep -n` で行番号を出す。

```bash
grep -n "承認" research/extracted/SRC-REVIEW-001.poppler.txt | head -30
```

**ページ番号は、その行までの改ページ文字の数で決まる。** poppler 版なら次で数えられる。

```bash
awk -v n=9183 'NR<=n{p+=gsub(/\f/,"")} END{print "p." p+1}' research/extracted/SRC-REVIEW-001.poppler.txt
```

pypdf 版なら、その行より前にある直近の `===== PAGE n =====` を探す。

```bash
awk 'NR<=6409 && /^===== PAGE [0-9]+ =====$/{p=$3} END{print "p." p}' research/extracted/SRC-REVIEW-001.pypdf.txt
```

**`p.` はPDFのページであり、紙の本のノンブルとは一致しない。** この注記は `research/sources.md` にある。出典に書くときも、PDFのページであることが分かる形で書く。

### 手順3 前後を読む

該当行だけで主張を書かない。前後を読む。

```bash
sed -n '9150,9230p' research/extracted/SRC-REVIEW-001.poppler.txt
```

読むときに確かめるのは次の3つである。

| 確かめること | なぜか |
|---|---|
| その記述が著者の主張か、紹介した他説か | 紹介を著者の主張として引くと出典を誤る |
| 条件が付いていないか | 「新人が多い場合」のような条件は要約で落ちやすい |
| 数値に測定の裏づけがあるか | 経験則と測定値では、読者の使い方が変わる |

### 手順4 出典の書き方を確かめる

出典は `<出典ID> p.<ページ>` の形で書く。章・節が本文から読み取れるなら添える。

```text
SRC-REVIEW-001 p.87（3.2）
```

**抽出テキストは書籍の本文である。確からしさは「一次資料」と数える。** 他者の要約ではない。

**要約で書く。連続する3文以上をそのまま写さない。** 抽出テキストは原本の複製にあたる。

## 確かめること

- [ ] 全文を読まずに、探してから読んだ
- [ ] ページ番号を添えた
- [ ] 該当行だけでなく前後を読んだ
- [ ] 著者の主張と、紹介された他説を区別した
- [ ] 連続する3文以上の転載が無い
