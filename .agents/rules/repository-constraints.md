# このリポジトリの制約

このリポジトリは、システム開発の進め方を書籍とWebの情報から整理して手引きにする。**本文は日本語で書き、ファイル名は英語の小文字とハイフンで付ける。**

## 書き込まない

**`docs/`、`research/`、`references/` に書き込まない。**

このリポジトリでの役割は調査である。調査の結果は最終メッセージとして返し、ファイルに置くのは依頼した側が行う。**誰が書いた成果物かを、あとから切り分けられるようにするためである。**

**この禁止は設定では止めていない。守るかどうかはこの規則にかかっている。** 書き込みの拒否を Antigravity の設定に入れると、このリポジトリ以外の作業でも書き込めなくなるためである。

## 参考書の本文を写さない

**連続する3文以上をそのまま写さない。要約で書く。**

`references/` の参考書PDFは購入者を特定できる情報を含み、`research/extracted/` はその複製にあたる。調査の成果物はGitで追跡するため、原文を写すと複製が公開範囲に出る。

引いてよいのは、主張を自分の言葉で要約した1行と、ページを指す出典IDである。

## 主張には出典を添える

**出典が無い記述には「出典なし・私見」と明記する。** 出典IDの一覧は `research/sources.md` にある。

書式は `.agents/skills/writing-interim-artifacts/SKILL.md` にある。**1行が1主張で、主張ID・根拠の所在・確からしさを必ず添える。**

資料を読んでいない主張は、確からしさを「推測」とする。**知識として知っていることも推測である。** 読者が原典をたどれないためである。

## 根拠に使ってよい発信元

**一次資料を根拠にする。** 一次資料とは、規格の本体、標準化団体の公式文書、査読つき論文、書籍の本文である。

まとめ記事や個人ブログの要約を根拠にしない。**言い換えの誤りを検出できないためである。** 見つけた場合は、たどって原典を探す。

取得を許しているホストは次のとおりである。2026-09-03 の時点の一覧である。

| ホスト | 何のために |
|---|---|
| `www.iso.org` | ISO/IEC の規格 |
| `google.github.io` | Google Engineering Practices |
| `martinfowler.com` | リファクタリングとテスト分類 |
| `www.ipa.go.jp` | 情報処理推進機構の公開文書 |
| `jstqb.jp`、`www.jstqb.jp`、`www.istqb.org` | テスト技術の用語と体系 |
| `www.jtf.jp` | 日本語標準スタイルガイド |
| `semver.org` | セマンティックバージョニング |
| `www.w3.org`、`datatracker.ietf.org` | Web と通信の仕様 |
| `smartbear.com`、`static0.smartbear.co` | コードレビューの事例研究 |
| `ht-0328.github.io` | 姉妹リポジトリの文書標準 |

**一覧に無いホストは取得できない。** Antigravity の設定 `~/.gemini/antigravity-cli/settings.json` の `permissions.allow` が `read_url` をこの一覧に絞っている。拒否されたら、そのホストを使わずに答え、「このホストが要る」と最終メッセージに書く。一覧を増やすかは依頼した側が決める。

## 実行しないコマンド

**次のコマンドを実行しない。** 調査が役目であり、リポジトリの状態を変えるのは依頼した側である。

| 種類 | コマンド |
|---|---|
| 履歴と公開を動かす | `git`、`gh` |
| 消す・動かす | `rm`、`mv`、`chmod`、`chown` |
| 外へ出る | `curl`、`wget`、`ssh`、`scp`、`rsync` |
| 入れる | `sudo`、`apt`、`apt-get`、`pip`、`pip3`、`npm`、`npx`、`cargo` |
| サンドボックスの外へ出る | `docker`、`podman` |

**この一覧も設定では止めていない。** 止めるには Antigravity のグローバル設定に `deny` を書くことになり、このリポジトリ以外の作業にも及ぶ。

**外への通信は、組み込みのURL取得だけを使う。** 経路が記録に残り、返した内容にURLが付くためである。

## 未解決の印を残さない

**`TBD`、`FIXME`、`???` を書かない。** 決まっていないことは、決まっていないと日本語で書く。何が決まっていないかと、決めるのに何が要るかを添える。
